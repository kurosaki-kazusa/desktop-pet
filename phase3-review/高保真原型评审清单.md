# 三期高保真原型评审清单

> 评审对象仅为正式应用窗口，不包含桌宠。建议在默认窗口与 960×640 最小窗口各检查一次。

## 1. 顶层信息架构

- [ ] 顶部只出现“提示词管理工具”“日程管理”“设置”三个入口。
- [ ] 点击入口直接切换完整页面，不出现下拉菜单或设置子栏目。
- [ ] 自定义标题栏与工作区符合“萤光织界”视觉标准。
- [ ] 所有界面中均没有桌宠本体或桌宠悬浮区域。

## 2. 提示词管理工具

- [ ] 左栏保持一级项目空间，能够新增、重命名与调整顺序。
- [ ] 删除非空空间时必须先确认迁移目标，不能静默丢失内容。
- [ ] 至少保留一个项目空间，最后一个空间的删除操作必须禁用。
- [ ] 提示词和命令使用同一套卡片、详情和编辑流程。
- [ ] 有封面内容显示大卡片，无封面内容显示紧凑卡片。
- [ ] 搜索、类型筛选和排序结果即时更新，并提供无结果空状态。
- [ ] 单击卡片打开右侧抽屉；复制按钮不会打开抽屉。
- [ ] 新建/编辑表单包含类型、空间、标题、正文、封面、置顶和收藏。
- [ ] 标题或正文为空时阻止保存并显示字段错误。
- [ ] 本地例图只在当前页面预览；命令界面没有执行入口。

## 3. 日程管理

- [ ] 默认只显示“长期待办”和“今日事项”两列，不出现已完成栏目。
- [ ] 长期待办使用同一日历依次选择开始日期与结束日期，区间首尾都包含。
- [ ] 当前查看日期处于任务区间内时，长期待办自动同时显示在今日事项；区间外自动退出今日事项。
- [ ] 今日事项可以手动新建只属于当天的偶发任务，并显示“当日新增”来源。
- [ ] 区间映射任务显示“来自长期待办”和完整日期区间，不复制任务数据。
- [ ] 完成任务后直接从活跃看板和日历移除，不进入已完成栏目。
- [ ] 点击任务可以编辑或进入删除确认。
- [ ] 删除带提醒的任务时，可选择“仅删除任务”或“任务和提醒一起删除”。
- [ ] 日程表只展示有日期的任务和定点提醒。
- [ ] 日程表以连续色带标记区间任务，开始和结束位置具有明确端点。
- [ ] 点击日期后出现当天详情侧栏，并提供当天快捷新建任务。
- [ ] 日期详情明确区分“区间任务”和“当日任务”的来源。
- [ ] 提醒管理保留定点、周期、使用时长三种语义及启停状态。
- [ ] 定点提醒可以选择并编辑日期，编辑未来提醒不会静默改回当前日期。
- [ ] 关联提醒在任务和提醒列表中都有明确反馈。

## 4. 设置

- [ ] 通用设置和大模型配置在同一个完整页面内展示。
- [ ] 开关和音量变化立即出现保存反馈。
- [ ] 接口地址格式错误时阻止保存并显示提示。
- [ ] API Key 不显示真实内容，页面明确说明原型不会读取密钥。
- [ ] 清空历史、退出应用和恢复数据均经过二次确认。

## 5. 尺寸与状态

- [ ] 默认尺寸下提示词卡片为三列、任务看板为两列，内容无重叠。
- [ ] 正文、辅助文字、表单和日历事件均达到新的可读字号基线。
- [ ] 960×640 下提示词卡片降为两列，主要操作仍可触达。
- [ ] 页面、抽屉、弹窗和日期侧栏不存在横向溢出。
- [ ] 刷新后新增、编辑、完成和设置全部恢复为预置案例。

## 6. 本轮不验收

- Electron 真实窗口控制、任务栏、多屏恢复和边缘缩放。
- 正式数据库、配置迁移、封面文件复制与磁盘持久化。
- 真实大模型调用、API Key 存储、提醒调度和系统通知。
- 桌宠动作、悬浮窗口、聊天气泡及桌宠与工作台之间的 IPC。
