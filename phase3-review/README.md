# 三期高保真原型评审包

本目录提供 AI 桌面应用三期的**正式应用窗口高保真原型**。原型不包含桌宠部分，不会读取或修改正式应用数据，也不会发起网络请求、执行命令或调用系统能力。

## 快速开始

双击 `界面示例.html` 即可评审。建议按以下顺序操作：

1. 在“提示词管理工具”中新建空间、新建内容，测试搜索、筛选、排序、收藏、复制、编辑与删除确认。
2. 切换“日程管理”，新建一个带开始/结束日期的长期待办，确认它在区间内自动进入“今日事项”；也可直接新建当日偶发事项。
3. 点击 8 月 25 日查看日期详情；测试新增、编辑、启停提醒。
4. 进入“设置”，修改开关与音量，验证大模型配置校验、清空历史和退出二次确认。
5. 刷新页面，确认所有操作恢复为预置案例数据。

## 本次达到的原型标准

| 区域 | 已覆盖的高保真状态 |
|---|---|
| 应用窗口 | 自定义标题栏、窗口按钮反馈、三个一级导航、默认与最小窗口布局 |
| 项目空间 | 一级分类、新建、重命名、排序、非空空间迁移删除、重复名称校验 |
| 提示词/命令 | 有图与无图卡片、CRUD、搜索、筛选、排序、置顶、收藏、复制、封面预览、空状态与字段校验 |
| 每日看板 | 长期待办/今日事项两列、区间自动映射、当日偶发事项、完成即移除、日期切换、搜索和提醒关联 |
| 日程表 | 月份切换、连续区间色带、当日任务、定点提醒、日期来源详情和当天快捷新建 |
| 提醒管理 | 定点/周期/使用时长提醒、CRUD、启停、任务关联反馈 |
| 设置 | 单一设置页面、通用设置、大模型配置校验、保存状态和危险操作确认 |

## 指定画面

- `界面示例.html?page=prompts`
- `界面示例.html?page=prompts&compose=1`
- `界面示例.html?page=prompts&drawer=1`
- `界面示例.html?page=schedule&view=board`
- `界面示例.html?page=schedule&view=board&task=range&picker=1`
- `界面示例.html?page=schedule&view=board&task=today`
- `界面示例.html?page=schedule&view=calendar&day=25`
- `界面示例.html?page=schedule&view=reminders`
- `界面示例.html?page=schedule&view=reminders&reminder=1`
- `界面示例.html?page=settings`

## 自动检查

在项目根目录运行：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
.\node_modules\.bin\electron.cmd phase3-review\capture-prototype.js
```

脚本会验证内容 CRUD、空间迁移与最后空间保护、长期任务区间映射、当日事项、完成移除、日历区间色带、定点提醒日期、关联任务删除分支、提醒启停、字号基线和横向溢出，并重新生成十张截图。

## 原型边界

- 数据只保存在当前页面内存；刷新或关闭后恢复示例数据。
- 窗口最小化、最大化和关闭为视觉反馈，不控制真实系统窗口。
- 本地封面只用 `FileReader` 在当前页面预览，不写入文件系统。
- API Key 使用虚假遮罩值；模型保存只做格式校验，不发起网络连接。
- 命令只能复制，原型中没有执行入口。
- 提醒不会触发系统声音、通知或桌宠动画。
