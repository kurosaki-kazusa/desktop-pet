# 三期高保真原型评审包

本目录提供 AI 桌面应用三期的**正式应用窗口高保真原型**。原型不包含桌宠部分，不会读取或修改正式应用数据，也不会发起网络请求、执行命令或调用系统能力。

## 快速开始

双击 `界面示例.html` 即可评审。建议按以下顺序操作：

1. 在“提示词管理工具”中新建空间、新建内容；确认封面只有“包含图片的卡片 / 无图片的紧凑卡片”两种形态，紧凑卡片选图后自动变为带图卡片，并测试正文与图片快速复制。
2. 切换“日程管理”，分别从两列的新增入口打开固定类型表单；确认高优先级长期任务在区间内进入“今日事项”，其他长期任务只在最后一周进入；当日事项的时间默认关闭、可按需启用。
3. 确认日程表日期格保持简洁，再点击 8 月 25 日查看该日事项详情；测试新增、编辑、启停提醒。
4. 进入“设置”，修改开关与音量，验证大模型配置校验、清空历史和退出二次确认。
5. 刷新页面，确认所有操作恢复为预置案例数据。

## 本次达到的原型标准

| 区域 | 已覆盖的高保真状态 |
|---|---|
| 应用窗口 | 自定义标题栏、窗口按钮反馈、三个一级导航、默认与最小窗口布局 |
| 项目空间 | 一级分类、新建、重命名、排序、非空空间迁移删除、重复名称校验 |
| 提示词/命令 | 两种固定卡片形态、定额文字、紧凑卡片选图升级、正文/图片快速复制、CRUD、搜索、筛选、排序和置顶 |
| 每日看板 | 两列固定类型新增、长期任务按优先级/最后一周映射、当日事项可选时间、完成即移除、日期切换、搜索和提醒关联 |
| 日程表 | 月份切换、纯日期视图、点击日期展示当日事项和当天快捷新建 |
| 提醒管理 | 定点/周期/使用时长提醒、CRUD、启停、任务关联反馈 |
| 设置 | 单一设置页面、通用设置、大模型配置校验、保存状态和危险操作确认 |

## 自动检查

在项目根目录运行：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
.\node_modules\.bin\electron.cmd phase3-review\capture-prototype.js
```

脚本会验证内容 CRUD、空间迁移与最后空间保护、固定类型任务入口、长期任务优先级/最后一周映射、当日事项可选时间与提醒默认状态、完成移除、日历无任务提示且日期详情可用、定点提醒日期、关联任务删除分支、提醒启停、字号基线和横向溢出，并重新生成十一张截图。

## 原型边界

- 数据只保存在当前页面内存；刷新或关闭后恢复示例数据。
- 窗口最小化、最大化和关闭为视觉反馈，不控制真实系统窗口。
- 本地封面只用 `FileReader` 在当前页面预览，不写入文件系统。
- API Key 使用虚假遮罩值；模型保存只做格式校验，不发起网络连接。
- 命令只能复制，原型中没有执行入口。
- 提醒不会触发系统声音、通知或桌宠动画。
