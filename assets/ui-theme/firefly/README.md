## 处理说明

- 羽饰保持原角色帧内容，仅做透明遮罩、边缘羽化、适度放大与锐化。
- 胸饰原始区域只有约 40px，直接放大会混入手部与服装，因此依据原帧的金色双晶片、青色核心和深色轮廓进行了高保真清理；没有保留身体或衣物。
- 两张页面背景使用本地角色素材作为配色与纹样参考生成，不包含角色、脸部、身体、文字或 UI 控件。
- 粒子、纹理和标题装饰属于派生素材，可在实现阶段降级为 CSS；它们不承担信息表达。
