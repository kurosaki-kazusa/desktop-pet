# 三期方案评审包

本目录是 AI 悬浮桌面宠物三期需求的独立评审产物，不会读写正式应用数据，也没有修改根目录中的应用代码。

## 快速评审

1. 双击打开 `界面示例.html`。
2. 点击顶部“提示词管理工具 / 日程管理 / 设置”切换三个一级页面。
3. 在提示词页尝试空间切换、搜索、类型筛选、收藏、复制和卡片详情抽屉。
4. 在日程页切换今日看板、日程表和提醒管理；任务卡可拖入其他列。
5. 对照 `三期需求头脑风暴与产品方案.md` 审查功能边界、数据迁移与验收标准。

## 文件说明

| 文件 | 用途 |
|---|---|
| `三期需求头脑风暴与产品方案.md` | 本轮确认后的完整产品与技术方案 |
| `界面示例.html` | 可交互界面原型入口 |
| `界面示例.css` | 原型视觉与响应式样式 |
| `界面示例.js` | 原型页面切换、筛选、抽屉和看板拖放交互 |
| `capture-prototype.js` | 离屏生成关键页面截图的 QA 辅助脚本 |
| `screenshots/` | 关键页面静态预览 |

## 原型参数

为便于直接打开指定画面，HTML 支持下列查询参数：

- `界面示例.html?page=prompts`
- `界面示例.html?page=prompts&drawer=1`
- `界面示例.html?page=schedule&view=board`
- `界面示例.html?page=schedule&view=calendar`
- `界面示例.html?page=schedule&view=reminders`
- `界面示例.html?page=settings`

## 视觉基线

- 延续当前“萤光织界”色彩和素材。
- 使用已有胸前晶体、羽饰、透明几何纹理与青/金/粉点缀。
- 不使用已禁用的 `diamond-mark` 元素。
- 三期正式工作台采用完整月白应用底面；桌宠窗口与聊天面板的透明原则保持不变。

## 原型限制

- 所有内容均为示例数据，刷新后重置。
- 窗口控制按钮仅展示正式应用窗外观。
- 新建、保存、删除、打开目录和退出等操作只显示反馈，不改变文件或系统状态。
- 拖放只改变当前页面中的卡片位置，不持久化。
- 原型不会发起网络请求，不读取 API Key，也不会执行命令。

## 建议评审顺序

1. 先看顶部信息架构与正式窗口比例。
2. 再看有图/无图提示词卡片的密度与详情抽屉。
3. 检查三列看板、月历和提醒管理是否属于同一日程工作流。
4. 检查设置页是否满足“一次点击切换、无子栏目”的要求。
5. 最后审查方案中的迁移、安全和分阶段实施边界。
