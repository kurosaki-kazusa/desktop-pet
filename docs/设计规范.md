## 1. 整体视觉风格

- **主题定位**：「萤光织界」——从当前桌宠的深蓝机甲、青色晶体、金色饰片、粉色点缀与白色羽饰中提取设计语言，保留柔和圆角，但不再使用通用蓝色设置页观感。
- **色彩令牌**：夜幕 `#0B1630`、钢蓝 `#1C3148`、萤青 `#54D7D7`、薄荷 `#7FCFCA`、晶金 `#EEAF49`、羽粉 `#F093AA`、警示珊瑚 `#DC7857`、月白 `#F5F2F0`。
- **层级**：聊天与配置都以月白半透明卡片承载内容，仅在卡片内使用羽饰、晶体、几何纹理和萤光粒子；禁止在卡片下方叠加不透明深色背景。
- **字体**：系统默认（`"Microsoft YaHei", sans-serif`），正文 15px，标题 16px 加粗
- **透明原则**：宠物窗口除宠物与对话/提醒卡片外保持完全透明；独立配置窗口也只显示设置卡片，卡片外围必须完全透明。

## 2. 宠物状态机与动画

| 状态 | 触发 | 实现 | 行为 |
|---|---|---|---|
| `idle` 待机 | 默认状态 | `action-07` 第一帧静止显示，每 20 秒播放一次完整 `action-07`，无大小缩放 | 静止为主，定时轻动作 |
| `action` 交互 | 左键单击 | 从 `action-01/02/03/04/05/08/09` 中随机播放一组逐帧动作 | 播完后自动回到 `idle` |
| `remind` 提醒 | 提醒触发 | `action-06` 逐帧循环 + 轻微弹跳 + 头顶提醒气泡 | 气泡关闭后回到 `idle` |

规则：
- `action-04` 的运行时路径暂时切换为 `action-04-interpolated`（8 帧、130ms/帧）进行实机观感测试；不满意可直接回退原 4 帧配置。
- 状态切换必须保证回到 `idle` 的兜底路径（动画播完 / 气泡关闭 / 超时 10 秒），不允许卡死在中间态
- 单击事件需与双击区分：使用 300ms 判定窗口（先判定是否双击，超时才执行单击动作），避免双击时误播两次交互动作
- 宠物显示尺寸：约 **176×188px**，位于窗口底部居中；图片帧透明区域不得出现实底色残留

## 3. 交互面板（双击触发，v2.0 取代原复制看板，v2.1 与配置中心入口对调）

- **定位**：双击宠物弹出的**对话交互面板**——上方回复气泡 + 底部输入框（后续接入大模型 agent 后实现真实对话）；打开即聚焦输入框，双击后可直接打字
- **造型**：圆角卡片 + 底部指向宠物的小三角箭头，宽度 380px；对话区最大高度约 220px（内容超出滚动），总高不超过 400px
- **结构**：羽翼标识 + 标题“和桌宠聊天” + 关闭按钮 + 对话区（聊天消息流）+ 输入区（透明角色 PNG 头像 + 输入框 + 发送按钮）
- **对话气泡**：宠物回复为左侧月白/薄荷气泡（带透明角色 PNG 头像），用户消息为右侧深青气泡（右对齐）；首次打开自动显示问候语“你好呀，今天过得怎么样？”
- **输入**：输入框支持回车或点“发送”提交（上限 500 字符）；大模型接入前，发送后以占位回复代替
- **关闭**：点击面板右上角 ✕，或点击宠物/面板以外的区域（依赖点击穿透策略，失焦即关闭）；关闭期间对话记录保留，重开不重置

## 3.5 配置中心（右键触发，v1.4 更新：独立窗口居中，宠物不动；v2.1 入口由双击改为右键）

- **定位**：右键宠物打开的**独立设置窗口**（第二个 BrowserWindow，700×680）——居中于鼠标所在屏，宠物窗口保持原位不动；全窗口可交互（无穿透）
- **拖动**：按住面板**头部标题区域**可拖动窗口到任意位置（Tab 栏与关闭按钮除外；不记忆位置，下次打开仍居中）
- **造型**：圆角大卡片，宽度 640px，最大高度约 648px，顶部以胸前晶体作为主题标识，标题为“配置中心” + 关闭按钮；窗口内垂直居中
- **关闭**：点右上角 ✕ 或按 Esc（窗口不复用宠物态窗口，无还原问题）
- **结构**：顶部 Tab 栏（`常用命令` / `提醒管理`）+ 底部“退出宠物”按钮（v2.0 从右键看板移入）
- **常用命令 Tab**（管理全部命令）：
  - 顶部**搜索框**：按命令标题关键词实时过滤（不区分大小写）；无匹配时显示空状态提示
  - 列表项 = 标题（置顶条目前加 📌）+ 命令内容（多行完整显示，点击复制）+ **置顶勾选**（右侧 checkbox，提示“置顶显示（排在列表最前面）”，无数量上限）+ 编辑/删除
  - 勾选置顶的条目自动排在列表最前（保持各自原有相对顺序）
  - 新增表单：标题 + **多行文本域**（textarea，可纵向拉高，支持跨行长文本/脚本，上限 2000 字符）+ 置顶勾选
- **提醒管理 Tab**：提醒管理唯一入口
- **关闭**：点击右上角 ✕，或点击宠物/面板以外的区域

## 4. 提醒气泡（提醒触发时）

- 从宠物头顶冒出，圆角小卡片，含：提醒图标 + 文本 + "知道了"按钮
- 自动停留 **8 秒**后淡出；点击"知道了"立即关闭
- 出现时伴随宠物 `remind` 动画与提示音

## 5. 音效

- 普通提醒：**WebAudio 合成的双音提示音**（正弦波 A5→D6 两音，总时长 <0.5 秒，v1.1 变更，原 mp3 文件）
- 使用时长提醒（看电脑 1 小时）：播放 `assets/audio.wav` 语音；如播放失败，回退普通双音提示音
- 音量默认 0.8，存于 `settings.volume`（一期不做音量调节 UI）

## 6. 动效与过渡

- 气泡/面板出现：`opacity + translateY(4px)` 淡入，150ms `ease-out`
- 消失：淡出 120ms
- 交互反馈不超过 300ms；环境粒子可使用 8–12s 低幅循环，仅动画 `transform/opacity`，且在 `prefers-reduced-motion` 下停止。

## 7. 素材方案（v2.6 · 透明 PNG 帧动画）

宠物本体为 `#pet > #pet-frame` 图片帧容器，素材位于 `assets/pet-actions/`。源文件 `docs/spritesheet.webp` 按从上到下 9 行切为 9 组动作，每组保留 `strip.png` 原始动作条，并生成 `frame-*.png` 逐帧透明 PNG：

| 状态 | 动画 | 说明 |
|---|---|---|
| 待机 | `action-07` 每 20 秒播放一次 | 静止为主，无缩放式大小浮动，避免持续播放造成视觉打扰 |
| 交互 | `action-01/02/03/04/05/08/09` 随机 | 左键单击随机选一组，播完回 idle |
| 提醒 | `action-06` + `bounce` | 提醒期间循环，气泡关闭后回 idle |

选型理由：真实角色素材表现力更高；逐帧 PNG 比直接滚动精灵条更能适配每帧不等宽的素材，且透明通道适合 Electron 透明悬浮窗。

素材更新路径：

1. 替换 `docs/spritesheet.webp`
2. 运行 `node scripts/slice-spritesheet.js` 重新生成 `assets/pet-actions/`
3. 如每行动作含义变化，同步调整 `renderer.js` 中 `PET_IDLE / PET_REMIND / PET_ACTIONS` 映射

音效同理：如后续需要真实音效文件，在 `assets/` 目录新增并替换 WebAudio 实现即可。

## 8. 三期正式工作台视觉（P3，v3.0 新增）

> 基准：`phase3-review/界面示例.html` 高保真原型（含记事本、默认打开界面等最终形态）。本节为三期实施的总视觉约束，各页面细节（卡片/抽屉/看板/月历/设置表单）以原型为准。

### 8.1 窗口与整体

- **窗口形态**：自定义无边框正式应用窗，默认 1180×760（最小 960×640）；自定义标题栏使用**深色钢蓝**（夜幕/钢蓝系），工作区使用**月白底面**——不再保留配置中心“透明窗口中单张卡片”的形态
- **顶部导航**：四项一级入口（记事本 / 提示词管理工具 / 日程管理 / 设置），点击直接切换主内容区完整页面；二级视图（月历/提醒管理）只在“日程管理”页内部切换
- **色彩**：沿用「萤光织界」令牌（夜幕 #0B1630、钢蓝 #1C3148、萤青 #54D7D7、薄荷 #7FCFCA、晶金 #EEAF49、羽粉 #F093AA、警示珊瑚 #DC7857、月白 #F5F2F0）
- **标识与装饰**：胸前晶体作为应用标识；羽饰与几何纹理作为低密度装饰；继续使用现有 `diamond-tile` 低对比纹理；禁止使用已移除的 `diamond-mark`

### 8.2 字号与密度

- 整体字号在二期视觉基线上**提升约 2px**：正文以 **14px** 为基线，导航、标题、表单与日历信息同步放大
- 空间不足时优先**纵向滚动**，不以压缩字号换取密度
- 卡片、输入框、按钮和动效继续遵守现有圆角与 **150ms** 反馈标准；环境粒子在 `reducedMotion`（减少动态效果设置）下停止

### 8.3 页面视觉要点（细节以原型为准）

- **提示词管理**：左侧空间侧栏 + 右侧卡片库；带图卡片（统一尺寸、固定 3 行正文、图片区独立复制按钮）与紧凑卡片（统一尺寸、固定 4 行正文）两种形态；详情抽屉从右侧滑入
- **记事本**：共用空间侧栏 + 板块卡片网格（标题/空间标签/3 行摘要/更新时间）；编辑态为类 Windows 记事本（大标题 + 等宽字体全高文本区 + 保存状态指示）
- **日程管理**：长期待办/今日事项两列看板（默认）+ 纯日期月历（日期格不显示任务提示）+ 提醒管理；任务卡显示标题、优先级、提醒状态、日期范围与来源；酒店式区间选择器
- **设置**：单页纵向分组（通用设置/大模型配置/应用级），不用子栏目导航；危险操作（退出宠物）弱化 + 二次确认

### 8.4 响应式与多屏

- 960×640 最小尺寸：卡片网格降列（两列/一列）、纵向滚动保证可读可操作
- 多屏与不同缩放环境：窗口恢复坐标不在任一显示器可见区时，回到鼠标所在屏幕中央
