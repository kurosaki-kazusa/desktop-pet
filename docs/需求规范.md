## 1. 项目定位

一个悬浮在 Windows 桌面上的 AI 宠物（桌宠），具备三大核心能力：

1. **提醒功能**：在固定时间/周期提醒用户做特定事情（喝水、休息眼睛、控制电脑使用时长等）
2. **常用命令记录器**：记录常用命令（在配置中心管理，支持置顶排序与点击复制）
3. **交互面板**：双击宠物弹出对话面板，与桌宠进行大模型流式对话（v2.3 接入 DeepSeek：多轮历史、思考区展示、上下文自动摘要压缩）

项目用于 vibe coding 课程的课堂演示，需在 **2 小时内**可完成开发。

## 2. 一期功能范围（本次开发）

### 2.1 提醒功能
| 需求点 | 说明 |
|---|---|
| 定点提醒 | 用户指定时刻触发，提醒内容为用户自定义文本 |
| 周期提醒 | 每 N 分钟触发一次，用于喝水、休息眼睛等场景 |
| 使用时长提醒 | 从应用启动累计运行时长，达到阈值提醒休息 |
| 时长预置 | 系统仅预置 60 分钟使用时长提醒，用户可修改；不预置护眼提醒；升级时移除未改动的旧版 45 分钟系统护眼预置 |
| 提醒数据模型 | 两种类型：`定点`（absolute）与 `周期`（interval），见技术规范 |
| 提醒表现 | 宠物切换提醒动画 + 提示音 + 气泡显示提醒内容 |
| 错过补偿 | 不做补偿，错过即错过（一期不实现） |

### 2.2 常用命令记录器
| 需求点 | 说明 |
|---|---|
| 记录命令 | 支持新增 / 编辑 / 删除常用命令（标题 + 命令内容，内容支持**跨行长文本**，上限 2000 字符） |
| 置顶排序 | 每条命令可勾选**置顶**（v2.0：原“显示在右键复制看板”改为置顶，无数量上限），置顶条目排在列表最前 |
| 打开入口 | 双击宠物打开**配置中心**（常用命令 Tab） |
| 持久化 | 命令数据关闭重开后不丢失 |

### 2.4 配置中心（v1.1 新增，v1.3 优化）

> 修改理由：右键便捷菜单如果过长则不够便捷，但日常需要用到的网页、命令或网站可能不止五条——将最常用的至多五条设置在便捷弹窗中，更多的则设置在大弹窗中，保证了便捷性，也保证了可用性。

| 需求点 | 说明 |
|---|---|
| 打开入口 | **右键宠物打开大配置框（配置中心）**（v2.1 由双击改为右键，符合“右键=设置”惯例），替代原提醒管理面板 |
| 独立窗口居中 | 配置中心是**独立设置窗口**（700×680），居中于鼠标所在屏（类似应用设置窗口）；**宠物窗口保持原位不动**（v1.3 修正：此前双击会让宠物随窗口一起移动） |
| 窗口可拖动 | 按住面板**头部（标题区域）**可拖动配置窗口到任意位置（v1.6 新增，不记忆位置，下次打开仍居中） |
| 全部命令管理 | 配置中心内管理**全部**常用命令：新增 / 编辑 / 删除，支持跨行长文本（多行命令/脚本） |
| 标题搜索 | 常用命令列表上方提供搜索框，按**命令标题关键词**实时过滤 |
| 置顶勾选 | 每条命令可勾选“置顶显示”（v2.0：原“显示在右键复制看板”改造，无数量上限），勾选的条目排在列表最前 |
| 提醒管理入口 | 原提醒管理功能移入配置中心 Tab（右键区域不再提供提醒管理） |
| 退出入口 | “退出宠物”按钮位于配置中心底部（v2.0 从右键看板移入） |
| 数据同步 | 配置窗口的增删改实时同步到宠物窗口（置顶状态立即生效） |
| 旧数据兼容 | 原“便捷命令”（quick）字段迁移为“置顶”（pinned）：quick=true 保持置顶，其余不置顶；无数量限制 |
| 视觉主题 | 卡片外围完全透明；月白卡片内使用胸前晶体标识、羽饰标题装饰与青/金/粉低密度粒子；禁用 `diamond-mark` 元素 |

### 2.5 交互面板（v2.0 变更取代原复制看板，v2.1 改为双击触发）

> 修改理由：右键快捷复制看板在实际体验中没有作用，改为**交互面板**——上方回复气泡 + 底部输入框，后续接入大模型 agent 实现对话；命令复制能力收敛到配置中心（点击命令内容仍可复制）。

| 需求点 | 说明 |
|---|---|
| 定位 | 双击宠物弹出的**对话交互面板**（v2.1 由右键改为双击，对话是高频主功能）：上方回复气泡 + 底部输入框（红色方框为输入框，输入框旁为宠物头像）；打开即聚焦输入框 |
| 默认问候语 | 首次打开面板时，回复气泡默认输出“你好呀，今天过得怎么样？” |
| 持续对话 | 后续回复持续使用对话气泡追加展示（气泡内滚动，打开期间保留会话记录） |
| 大模型接入 | ✅ 已实现（v2.3）：双击面板发送消息后由 DeepSeek 大模型生成回复（流式逐字渲染）；配置中心「大模型」页签可填 Key/地址/模型/人设，留空则读项目根目录 `.env`（填 `DEEPSEEK_API_KEY` 重启即用）；支持多轮历史（默认 12 轮，超出自动摘要压缩）、deepseek-reasoner 思考区展示、空回复重试一次、超窗/无 Key 错误归一提示 |
| 能力范围 | 仅对话交互：**无**命令展示/复制/配置能力（复制收敛到配置中心） |
| 视觉主题 | 卡片外围完全透明；月白聊天卡片内使用羽翼飘带标识、透明几何纹理、青/金/粉萤光粒子和青色对话强调；禁用 `diamond-mark` 元素 |

### 2.3 明确不做（一期边界）
- ❌ 打开本地文件/文件夹
- ❌ 命令搜索
- ❌ 命令执行
- ❌ 系统通知（仅应用内气泡）
- ❌ 每日重复规则、错过提醒补偿

## 3. 交互框架（已确认）

| 状态/操作 | 行为 |
|---|---|
| 日常待机 | 宠物以**呼吸动画**活动 |
| 提醒触发 | 宠物切换**特殊提醒动画** + 播放**提示音** |
| 左键单击 | 播放宠物**交互动作**（多套预设动作随机） |
| 左键双击 | 打开**交互面板**（对话气泡 + 输入框，默认问候语，打开即聚焦输入框；v2.3 起发送消息由大模型流式回复，含思考区与打字光标） |
| 右键单击 | 打开**配置中心**（独立设置窗口：居中于鼠标所在屏，宠物保持原位，头部可拖动；全部常用命令管理 + 标题搜索 + 提醒管理） |
| 拖动 | 支持拖动移动宠物位置，并记忆关闭前位置 |

## 6. 验收总标准

- 应用启动后宠物悬浮于桌面最顶层，背景完全透明
- 关闭重开后，提醒与命令数据均保留
- 全部提醒类型（定点/周期/时长）可正常触发并三合一呈现
- 全程无崩溃、无明显卡顿

## 7. 三期功能范围 · 正式工作台（P3，v3.0 新增）

> 三期把原“配置中心”升级为可长期使用的正式桌面工作台。基准：`phase3-review/界面示例.html` 高保真原型与《三期需求头脑风暴与产品方案》。实施顺序见《开发步骤》P3-M0~M8。

### 7.1 项目定位补充

在三大核心能力（提醒/常用命令记录器/大模型对话）基础上，新增四项一级能力：

1. **记事本**：零配置随手记录，打开即写、输入自动保存（约 500ms 防抖 + 保存状态指示）
2. **提示词管理工具**：统一管理提示词和常用命令（一级项目空间 + 统一卡片模型）
3. **日程管理**：长期待办/今日事项两列看板、纯日期月历、提醒管理整合
4. **设置**：同一完整页面管理通用配置与大模型配置

桌宠本体能力（悬浮/拖动/单击动作/双击对话/提醒触发）全程不受影响。

### 7.2 正式工作台窗口

| 需求点 | 说明 |
|---|---|
| 打开入口 | 右键桌宠打开工作台独立窗口（已打开时只恢复聚焦不重复创建）；双击桌宠仍打开对话面板 |
| 窗口形态 | 自定义无边框正式应用窗：显示任务栏、最小化/最大化/还原、边缘缩放 |
| 推荐尺寸 | 默认 1180×760，最小 960×640（缩小时允许纵向滚动，不压缩字号） |
| 位置尺寸 | 持久化；显示器变化后按现有多屏边界策略修正到可见区域 |
| 默认页面 | 打开时进入用户设置的「默认打开界面」（首次 = 提示词管理工具）；未设置时恢复上次停留页面 |
| 退出语义 | 关闭工作台不退出桌宠；「退出宠物」（设置页，二次确认）是唯一显式退出入口 |

### 7.3 提示词管理工具

| 需求点 | 说明 |
|---|---|
| 一级项目空间 | 仅一级分类：新建/重命名/拖动排序/删除空空间；非空删除可选“迁移到其他空间”（默认推荐）或“一并删除内容”；重名拦截 |
| 统一内容模型 | 提示词与命令共享字段（标题/正文/空间/封面/置顶/时间戳），`type: prompt|command` 仅作标签与筛选，不形成两套 CRUD |
| 工具栏 | 标题正文全文搜索；全部/提示词/命令筛选；置顶优先/最近更新/标题排序；新建内容 |
| 卡片形态 | 带图卡片（统一尺寸，固定 3 行正文，图片区独立复制按钮）/紧凑卡片（统一尺寸，固定 4 行正文，选图自动升级）；单击打开右侧详情抽屉 |
| 详情抽屉 | 编辑全字段、切换卡片形态、上传/替换/删除封面、移动空间、置顶、删除；双击正文快速复制 |
| 命令安全 | 只存储与复制，永不执行（不变） |
| 封面管理 | 本地选择/拖拽 PNG/JPEG/WebP，主进程校验类型与大小后复制到 `userData/prompt-covers/`；不支持网络 URL；缺失损坏显示主题占位图 |

### 7.4 记事本

| 需求点 | 说明 |
|---|---|
| 空间共用 | 与提示词管理共用一级项目空间侧栏（全部笔记 + 空间计数徽标） |
| 列表 | 板块卡片网格（标题/空间标签/3 行摘要/更新时间）+ 标题正文搜索 + 最近更新排序 |
| 零配置新建 | 「新建内容」无需任何配置：立即创建并打开类 Windows 记事本编辑视图（大标题 + 等宽全高文本区） |
| 自动保存 | 防抖自动保存（约 500ms）+ 保存状态指示；支持返回列表/重开/删除 |
| 空间同步 | 空间增删迁移同步两侧；删除空间时笔记随迁移或删除策略 |

### 7.5 日程管理

| 需求点 | 说明 |
|---|---|
| 今日看板 | 长期待办/今日事项两列（无已完成栏目）；各自栏目入口固定类型新建，编辑不可换型 |
| 日期区间 | 酒店式区间选择器（首尾均含；结束早于开始阻止保存） |
| 映射规则 | 高优先级长期任务区间全程进入今日事项；普通/低优先级仅结束日前最后 7 天（含结束日）映射；区间外自动退出；映射不复制数据 |
| 当日事项 | 事项日期、可选时间（默认关闭置灰）、来源标识、手动新建；完成即从看板与日历移除 |
| 顶部工具栏 | 前后日期/回到今天/搜索/新增长期待办/切日程表与提醒管理 |
| 月历 | 纯日期网格（日期格不显示任务提示）；点击日期侧栏详情（区间任务/当日任务标注 + 快捷新建）；提供返回今日看板 |
| 提醒管理 | 保留三类提醒 CRUD/启停/触发语义，仅重排视觉 |
| 提醒关联 | 任务「到点提醒」创建关联定点提醒（reminderId）；删除任务弹分支确认（仅删任务/连同提醒）；删除提醒只解绑不删任务；关联操作在主进程事务中完成 |

### 7.6 设置页

| 需求点 | 说明 |
|---|---|
| 布局 | 单页纵向分组，不用下拉菜单/弹窗/二级页签 |
| 通用设置 | 默认打开界面（记事本/提示词管理工具）、始终置顶、开机启动、提醒音量、减少动态效果、数据存储位置 + 打开目录 |
| 大模型配置 | 迁移现有 chat 配置（Key/地址/模型/人设）、保存、清空历史；Key 安全红线不变 |
| 应用级 | 版本信息、数据目录入口、退出宠物（二次确认） |
| 即时生效 | 布尔开关与音量即时生效 + 简短保存状态提示 |

### 7.7 数据模型与旧数据迁移（schema v3）

- 数据模型：`spaces/entries/notes/tasks/reminders/settings`（完整定义见技术规范 §4.5）；日期使用本地日历日期 `YYYY-MM-DD`；关联使用 ID 不嵌套复制
- 迁移规则（启动一次性执行）：①低于 v3 时先备份旧 commands/reminders/settings ②创建默认「常用命令」空间 ③每条旧命令转 entry（标题/正文/pinned 保留，type=command，归入默认空间）④旧 reminders 原样保留，不转任务 ⑤settings 补安全默认值（旧值优先）⑥全部校验通过才写 `schemaVersion: 3`；失败不删旧字段不写版本号 ⑦旧 commands 字段保留一个版本周期后再清理

### 7.8 三期验收标准

以《三期需求头脑风暴与产品方案》§12 为准，要点：工作台窗口行为与多屏适配、提示词/命令统一管理闭环、记事本即建即开自动保存、任务映射边界与提醒关联分支、设置即时生效与 Key 安全红线、桌宠对话/提醒触发/命令复制/置顶保活/拖动全部无回归。

### 7.9 三期明确不做

- ❌ 二级或多级项目空间、提示词变量模板、批量运行、版本历史、云同步
- ❌ 网络封面 URL、表格/画廊双模式
- ❌ 命令执行、文件执行、Agent 工具调用（不变）
- ❌ 周/日时间轴、复杂重复日程、错过补偿
