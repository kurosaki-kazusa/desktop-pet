> 版本：v2.3 ｜ 状态：已确认（v2.0 右键交互面板取代复制看板、命令置顶、退出入口移入配置中心；v2.1 交互入口对调：双击=对话面板、右键=配置中心，更符合 Windows 惯例与高频功能优先；v2.3 大模型会话接入：流式陪伴对话，.env 填 Key 即用）

## 1. 项目定位

一个悬浮在 Windows 桌面上的 AI 宠物（桌宠），具备三大核心能力：

1. **提醒功能**：在固定时间/周期提醒用户做特定事情（喝水、休息眼睛、控制电脑使用时长等）
2. **常用命令记录器**：记录常用命令（在配置中心管理，支持置顶排序与点击复制）
3. **交互面板**：双击宠物弹出对话面板，与桌宠进行大模型流式对话（v2.3 接入 DeepSeek：多轮历史、思考区展示、上下文自动摘要压缩）

项目用于 vibe coding 课程的课堂演示，需在 **2 小时内**可完成开发。

## 2. 一期功能范围（本次开发）

### 2.1 提醒功能
| 需求点 | 说明 |
|---|---|
| 定点提醒 | 用户指定时刻触发，提醒内容为用户自定义文本 |
| 周期提醒 | 每 N 分钟触发一次，用于喝水、休息眼睛等场景 |
| 使用时长提醒 | 从应用启动累计运行时长，达到阈值提醒休息 |
| 护眼/时长预置 | 系统预置默认间隔（护眼 45 分钟 / 时长 60 分钟），用户可修改 |
| 提醒数据模型 | 两种类型：`定点`（absolute）与 `周期`（interval），见技术规范 |
| 提醒表现 | 宠物切换提醒动画 + 提示音 + 气泡显示提醒内容 |
| 错过补偿 | 不做补偿，错过即错过（一期不实现） |

### 2.2 常用命令记录器
| 需求点 | 说明 |
|---|---|
| 记录命令 | 支持新增 / 编辑 / 删除常用命令（标题 + 命令内容，内容支持**跨行长文本**，上限 2000 字符） |
| 置顶排序 | 每条命令可勾选**置顶**（v2.0：原“显示在右键复制看板”改为置顶，无数量上限），置顶条目排在列表最前 |
| 打开入口 | 双击宠物打开**配置中心**（常用命令 Tab） |
| 持久化 | 命令数据关闭重开后不丢失 |

### 2.4 配置中心（v1.1 新增，v1.3 优化）

> 修改理由：右键便捷菜单如果过长则不够便捷，但日常需要用到的网页、命令或网站可能不止五条——将最常用的至多五条设置在便捷弹窗中，更多的则设置在大弹窗中，保证了便捷性，也保证了可用性。

| 需求点 | 说明 |
|---|---|
| 打开入口 | **右键宠物打开大配置框（配置中心）**（v2.1 由双击改为右键，符合“右键=设置”惯例），替代原提醒管理面板 |
| 独立窗口居中 | 配置中心是**独立设置窗口**（700×680），居中于鼠标所在屏（类似应用设置窗口）；**宠物窗口保持原位不动**（v1.3 修正：此前双击会让宠物随窗口一起移动） |
| 窗口可拖动 | 按住面板**头部（标题区域）**可拖动配置窗口到任意位置（v1.6 新增，不记忆位置，下次打开仍居中） |
| 全部命令管理 | 配置中心内管理**全部**常用命令：新增 / 编辑 / 删除，支持跨行长文本（多行命令/脚本） |
| 标题搜索 | 常用命令列表上方提供搜索框，按**命令标题关键词**实时过滤 |
| 置顶勾选 | 每条命令可勾选“置顶显示”（v2.0：原“显示在右键复制看板”改造，无数量上限），勾选的条目排在列表最前 |
| 提醒管理入口 | 原提醒管理功能移入配置中心 Tab（右键区域不再提供提醒管理） |
| 退出入口 | “退出宠物”按钮位于配置中心底部（v2.0 从右键看板移入） |
| 数据同步 | 配置窗口的增删改实时同步到宠物窗口（置顶状态立即生效） |
| 旧数据兼容 | 原“便捷命令”（quick）字段迁移为“置顶”（pinned）：quick=true 保持置顶，其余不置顶；无数量限制 |

### 2.5 交互面板（v2.0 变更取代原复制看板，v2.1 改为双击触发）

> 修改理由：右键快捷复制看板在实际体验中没有作用，改为**交互面板**——上方回复气泡 + 底部输入框，后续接入大模型 agent 实现对话；命令复制能力收敛到配置中心（点击命令内容仍可复制）。

| 需求点 | 说明 |
|---|---|
| 定位 | 双击宠物弹出的**对话交互面板**（v2.1 由右键改为双击，对话是高频主功能）：上方回复气泡 + 底部输入框（红色方框为输入框，输入框旁为宠物头像）；打开即聚焦输入框 |
| 默认问候语 | 首次打开面板时，回复气泡默认输出“你好呀，今天过得怎么样？” |
| 持续对话 | 后续回复持续使用对话气泡追加展示（气泡内滚动，打开期间保留会话记录） |
| 大模型接入 | ✅ 已实现（v2.3）：双击面板发送消息后由 DeepSeek 大模型生成回复（流式逐字渲染）；配置中心「大模型」页签可填 Key/地址/模型/人设，留空则读项目根目录 `.env`（填 `DEEPSEEK_API_KEY` 重启即用）；支持多轮历史（默认 12 轮，超出自动摘要压缩）、deepseek-reasoner 思考区展示、空回复重试一次、超窗/无 Key 错误归一提示 |
| 能力范围 | 仅对话交互：**无**命令展示/复制/配置能力（复制收敛到配置中心） |

### 2.3 明确不做（一期边界）
- ❌ 打开本地文件/文件夹
- ❌ 命令搜索
- ❌ 命令执行
- ❌ 系统通知（仅应用内气泡）
- ❌ 每日重复规则、错过提醒补偿

## 3. 交互框架（已确认）

| 状态/操作 | 行为 |
|---|---|
| 日常待机 | 宠物以**呼吸动画**活动 |
| 提醒触发 | 宠物切换**特殊提醒动画** + 播放**提示音** |
| 左键单击 | 播放宠物**交互动作**（多套预设动作随机） |
| 左键双击 | 打开**交互面板**（对话气泡 + 输入框，默认问候语，打开即聚焦输入框；v2.3 起发送消息由大模型流式回复，含思考区与打字光标） |
| 右键单击 | 打开**配置中心**（独立设置窗口：居中于鼠标所在屏，宠物保持原位，头部可拖动；全部常用命令管理 + 标题搜索 + 提醒管理） |
| 拖动 | 支持拖动移动宠物位置，并记忆关闭前位置 |

## 4. 交互面板内容结构（v2.0，v2.1 改为双击触发）

```
┌─────────────────────────┐
│  交互面板（指向宠物的箭头）  │
│  💬 和桌宠聊天          ✕ │
│  ┌───────────────────┐   │
│  │ 🐱 你好呀，今天过得  │   │  ← 回复气泡：默认问候语，
│  │    怎么样？        │   │    后续回复持续追加
│  │       [用户消息]    │   │
│  └───────────────────┘   │
│  [🐱| 输入框        |发送] │  ← 红色方框为输入框
└─────────────────────────┘
```

关闭方式：点击桌面空白处 或 面板关闭按钮。

## 4.5 配置中心内容结构（v1.3 更新：独立窗口居中，宠物不动）

```
┌───────────────────────────┐
│  配置中心（右键打开，独立居中窗） │
│  ⚙️ 配置中心           ✕  │
│  ┌─────────┬─────────┐   │
│  │ 常用命令 │ 提醒管理 │   │  ← Tab 切换
│  └─────────┴─────────┘   │
│  [🔍 按标题关键词搜索命令]   │  ← 常用命令 Tab 顶部搜索框
│  [全部命令列表 + 置顶勾选]   │  ← 每条命令带“置顶显示”勾选（打勾排最前）
│  [新增表单（支持跨行长文本）] │
│  [提醒管理列表]            │
│               [退出宠物]  │  ← v2.0 从右键看板移入
└───────────────────────────┘
```

关闭方式：配置中心关闭按钮（✕）或按 Esc。

## 6. 验收总标准

- 应用启动后宠物悬浮于桌面最顶层，背景完全透明
- 关闭重开后，提醒与命令数据均保留
- 全部提醒类型（定点/周期/时长）可正常触发并三合一呈现
- 全程无崩溃、无明显卡顿
